    Run it from a terminal

    docker compose -f docker/docker-compose.yml up -d mosquitto   # local broker
python -m dashboard.backend                                   # this dashboard (http://127.0.0.1:8080)
python run_demo.py --duration 60                              # external gateway: telemetry appears via MQTT
python -m scenarios.resilience_demo                           # scripted outage → buffering → FIFO replay check

    External gateways (another terminal, or the Compose app container) are observed through their MQTT telemetry only. Their GatewayMetrics live in that other process, so the metrics panel shows only runs hosted here. Pass --external-buffer edge_gateway/data/buffer.db to also watch run_demo.py's buffer depth, read-only.
